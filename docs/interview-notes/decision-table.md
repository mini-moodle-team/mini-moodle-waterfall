# 需求決定表 v1.0

- 來源：需求獲取問卷（2026/10/29，回覆 3/3：RA、QA、SD）、`form-responses.csv`
- 統計規則：單選取多數；複選取 2 人以上勾選的選項；八項核心功能以外的額外功能，預設「不做，列為未來功能」
- 統計後衝突的處理原則：以「實作最簡單、先做出可用系統」為優先（RA 決定，2026/10/30）
